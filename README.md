# caesar-cipher-analysis
# Анализ стойкости шифра Цезаря & Консольное приложение

Проект включает в себя программную реализацию классического алгоритма шифрования на языке **Python**, а также полноценное теоретическое и практическое исследование уязвимостей данного шифра.

## 📂 Структура репозитория
* `main.py` — точка входа, отвечающая за консольный интерфейс взаимодействия с пользователем.
* `caesar.py` — изолированный программный модуль, содержащий функции шифрования и дешифрования текстовых массивов.
* `caesar_cipher.exe` — скомпилированная версия приложения для запуска на ОС Windows без необходимости установки интерпретатора Python.
* `Анализ_стойкости_шифра_Цезаря.docx` — документация индивидуального проекта (теоретическая база, анализ криптостойкости и методы частотного криптоанализа).

## 🛠 Технологии
* **Язык:** Python 3
* **Сборка:** PyInstaller (для генерации .exe)
* **Интерфейс:** CLI (Консольный)

## 🚀 Функционал программы
* Шифрование и расшифрование текста с использованием пользовательского ключа (шага сдвига).
* Корректная обработка алфавитов (кириллица, латиница) с сохранением регистра символов, знаков препинания и пробелов.
* Модульная архитектура, позволяющая использовать криптографический блок в других проектах.
